# 四色定理教學地圖產生器

純 HTML/CSS/JS 工具，產生不規則區塊的長方形地圖，用於四色定理教學。

**線上使用**：https://buffalobill-taiwan.github.io/map4c/

## 使用方式

1. 輸入**寬度**、**高度**、**區塊數量**
2. 按下 **[產生地圖]** — 產生黑白線稿平面圖
3. 點擊色圈選取顏色（紅 / 藍 / 綠 / 黃），或**在畫布上滾動滑鼠滾輪**切換顏色
4. 點擊**區塊**填色 — 若相鄰區塊顏色相同則阻擋並警告
5. Hover 區塊時，若可著色則半透明預覽 + `pointer` 游標；若衝突則 `not-allowed` 游標
6. **[重設著色]** 清除所有顏色回到黑白線稿
7. 可反覆按 **[產生地圖]** 取得不同隨機佈局

## 演算法

**Voronoi 分割 + 貝茲曲線邊界**：

1. **種子生成** — 在長方形內隨機放置 N 個種子點，強制最小間距確保區塊不會太小
2. **半平面裁剪** — 對每個種子，以其與其他種子的垂直平分線裁剪長方形，得到 Voronoi 多邊形
3. **曲線邊界** — 內部共享邊以二次貝茲曲線繪製，模擬自然地圖邊界；外框保持直線
4. **著色** — `isPointInPath` 點擊偵測 + 鄰接圖衝突檢測，確保四色約束
