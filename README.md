# 四色定理教學地圖產生器

純 HTML/CSS/JS 工具，產生不規則區塊的長方形地圖，用於四色定理教學。

## 使用方式

直接於瀏覽器開啟 `index.html`。

1. 輸入**寬度**、**高度**、**區塊數量**
2. 按下 **[產生地圖]**
3. 地圖以純黑白線稿顯示，可直接列印讓學生手動著色
4. 反覆按可按鈕取得不同的隨機佈局

## 演算法

**Voronoi 分割**：

1. **種子生成** — 在長方形內隨機放置 N 個種子點，強制最小間距確保區塊不會太小
2. **半平面裁剪** — 對每個種子，以其與其他種子的垂直平分線裁剪長方形，得到 Voronoi 多邊形
3. **曲線邊界** — 內部共享邊以二次貝茲曲線繪製，模擬自然地圖邊界；外框保持直線
4. **繪製** — Canvas 白底黑線 2px，無任何顏色
