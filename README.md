# 四色定理教學地圖產生器

純 HTML/CSS/JS 工具，產生不規則區塊的長方形地圖，用於四色定理教學。

**線上使用**：https://buffalobill-taiwan.github.io/map4c/

## 使用方式

1. 輸入**寬度**、**高度**、**區塊數量**（最少 2 個）
2. 按下 **[產生地圖]** — 產生黑白線稿平面圖，自動選取紅色
3. 點擊色圈選取顏色（紅 / 藍 / 綠 / 黃／✕ 取消色），或**滾動滑鼠滾輪**切換顏色
4. 點擊**區塊**填色 — 若相鄰區塊顏色相同則阻擋並警告
5. Hover 區塊時，若可著色則半透明預覽 + `pointer` 游標；若衝突則 `not-allowed` 游標
6. **[自動著色]** — 一鍵自動完成四色著色，使用 **Kempe Chain** 演算法逐步演示
   - 每次著色或交換顏色皆暫停 **0.2 秒**，讓使用者看清演算法流程
   - 過程中按鈕變為「中止」，點擊可隨時停止
   - 自動著色完成**不會**觸發撒花與音效
7. **[重設著色]** 清除所有顏色回到黑白線稿
8. **[上一步]** 還原至上一次著色前的狀態（可連續按）
9. **🎉 全部著色完成時** — 畫面撒花 + 上行音階慶祝
10. 可反覆按 **[產生地圖]** 取得不同隨機佈局

## 演算法

**Voronoi 分割 + 貝茲曲線邊界**：

1. **種子生成** — 在長方形內隨機放置 N 個種子點，強制最小間距確保區塊不會太小
2. **半平面裁剪** — 對每個種子，以其與其他種子的垂直平分線裁剪長方形，得到 Voronoi 多邊形
3. **曲線邊界** — 內部共享邊以二次貝茲曲線繪製，模擬自然地圖邊界；外框保持直線
4. **著色** — `isPointInPath` 點擊偵測 + 鄰接圖衝突檢測，確保四色約束
5. **自動著色** — **Kempe Chain** 貪婪著色搭配連鎖交換，逐步演示無法直接著色時的顏色交換過程
